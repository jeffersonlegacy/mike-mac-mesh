# Route: documents and media

Use for locating, creating, transforming, or verifying personal and project artifacts.

1. Identify the authoritative source file and the intended final destination before generating output.
2. Preserve originals. Prefer a new output file or a symlink-based staging pattern when local media is already organized elsewhere.
3. Use the installed specialist skill when applicable (for example `documents`, `pdf`, `presentations`, `media-use`, or `build-project-story-blog`). Read its entry instructions before work.
4. Verify the actual artifact: open/render the document or inspect the media output and compare it with the requested details.
5. Keep private/personal identity and source provenance explicit; don't infer identity from a same-name file.

## Useful locations

- Personal and business documents: `~/Documents/`
- Local media roots: `~/Media/`, `~/Movies/`, `~/Pictures/`
- Shared or staged work products may use `~/Documents/New project/output/`; check the user's requested destination rather than assuming it.
