# Route: efficient agent work

Use when choosing scope, context, or verification for a task.

1. State the desired outcome in one sentence. Identify constraints already present in the request before asking anything.
2. Route to one playbook; inspect one authoritative source before secondary sources. Search narrowly, then open only relevant files.
3. Reuse existing plans, repo instructions, and verified memory. Do not restate or reload what is already available.
4. Batch dependent edits into one coherent change. Avoid speculative parallel work and broad discovery when a direct lookup will do.
5. Match effort to impact: small reversible change, focused verification; high-impact change, targeted runtime evidence and independent checks.
6. Return concise evidence: changed paths, outcome, verification, and unresolved limits. Avoid dumping logs or full inventories.
